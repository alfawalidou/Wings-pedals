# Contributing

Contributions that improve pedal firmware, calibration, mechanical documentation, or simulator integration are welcome.

## Guidelines

- Document controller board, wiring, sensor type, and pin assignments when relevant.
- Keep calibration or HID changes reproducible and easy to test.
- Do not commit personal device identifiers, credentials, or machine-specific secrets.
- Include before/after behavior for calibration or axis-mapping fixes.
- Update documentation when hardware assumptions change.

Pull requests should explain what changed, why it is needed, and how it was tested.
